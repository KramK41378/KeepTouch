# KeepTouch

> Веб-приложение, которое позволяет пользователям создавать посты, делиться ими в сети и взаимодействовать с контентом других пользователей.

---

## Описание

| Шаг | Действие |
|-----|----------|
| 1.  | **Регистрация** — пользователь создаёт аккаунт и входит в систему |
| 2.  | **Лента постов** — просмотр и скроллинг публикаций других пользователей |
| 3.  | **Создание поста** — загрузка фото и добавление описания в своём профиле |
| 4.  | **Редактирование профиля** — изменение имени и описания профиля |

---

## Структура проекта

KeepTouch/
├── main.py                   # Точка входа и маршруты Flask
├── requirements.txt          # Зависимости Python
├── .env                      # Переменные окружения (не коммитить!)
├── templates/                # Jinja2 шаблоны
│   ├── main.html             # Главная страница / профиль
│   ├── profile.html          # Профиль пользователя
│   ├── edit_profile.html     # Редактирование профиля
│   ├── create_post.html      # Создание поста
│   └── policy.html           # Политика конфиденциальности
├── static/
│   ├── styles/
│   │   └── style_main.css    # Стили (у каждой страницы своя тема)
│   └── images/               # Статические изображения (иконки, логотипы)
├── uploads/                  # Загруженные пользователями изображения
├── server/                   # Бэкенд-логика и утилиты
└── README.md                 # Этот файл

## Особенности дизайна

-Тёмная тема с градиентным фоном
-Glassmorphism — эффект матового стекла на карточках
-Полная адаптивность — корректное отображение на мобильных и десктопах
-Плавные анимации и микро-интерактивы при наведении
-Единая цветовая схема на основе #3498db и #27ae60

## Технологии

Backend: Python, Flask
Frontend: HTML, CSS
База данных: SQLite / SQLAlchemy
Аутентификация: Flask-Login (опционально)
Хранение файлов: Локальная папка uploads/ BD
